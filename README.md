# SmartXML

**SAP S/4HANA XML File Viewer for macOS**

SmartXML lets you open and view XML files from SAP S/4HANA extractions in a readable table format, with dynamic columns, sorting, filtering, and CSV export.

## Features

- Opens SAP ABAP XML files (STRUCTNAME / NAMETAB / DATA structure)
- Column display with per-column sorting and filtering
- Global real-time search
- Tabs for opening multiple files simultaneously
- Metadata panel (data type, length, primary key, nullable)
- CSV export compatible with Excel (UTF-8 BOM)
- Drag & drop XML files

## Requirements

- macOS 14.0 (Sonoma) or later

## Support

To report a bug or ask a question, open an [issue](https://github.com/stefenry/SmartXML/issues).

## Privacy Policy

SmartXML does not collect, store, or transmit any personal data. All files are processed locally on your Mac. See our [privacy policy](https://github.com/stefenry/SmartXML/blob/main/PRIVACY.md).
