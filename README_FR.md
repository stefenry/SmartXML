# SmartXML

**Visualiseur de fichiers XML SAP S/4HANA pour macOS**

SmartXML permet d'ouvrir et de visualiser les fichiers XML issus d'extractions SAP S/4HANA dans un format tabulaire lisible, avec colonnes dynamiques, tri, filtres et export CSV.

## Fonctionnalites

- Ouverture de fichiers XML SAP ABAP (structure STRUCTNAME / NAMETAB / DATA)
- Affichage en colonnes avec tri et filtres par colonne
- Recherche globale en temps reel
- Onglets pour ouvrir plusieurs fichiers simultanement
- Panneau de metadonnees (type, longueur, cle primaire)
- Export CSV compatible Excel (UTF-8 BOM)
- Glisser-deposer de fichiers XML

## Configuration requise

- macOS 14.0 (Sonoma) ou ulterieur
